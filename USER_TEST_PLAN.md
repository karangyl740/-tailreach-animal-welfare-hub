# Usability test plan

**Purpose:** Check whether the core front-end journey is understandable and usable. This plan is not evidence that testing has already been done.

## Participants
Recruit 3–5 volunteers who have not built the project. Do not collect unnecessary demographic information. Ask permission before taking notes; names are not needed.

## Tasks
1. Find a medical-care campaign.
2. Explain in your own words whether its progress number is real or illustrative.
3. Find the campaign's latest update / next step.
4. Share a campaign or copy its link.
5. Open the volunteer form and complete it with fictional test information.

## Record for each task
- Success: completed independently / completed with help / not completed.
- Time (optional): rough seconds, only if you can observe consistently.
- Hesitation or confusion: what happened, not your assumption about why.
- Participant's words: brief note, without identifying information.

## Fix priority
Address issues that block task completion first, then unclear labels, then cosmetic details. Re-test the changed task if possible.

## Report template
- Participants: [actual count]
- Most common issue observed: [specific behaviour]
- Change made: [specific UI/content change]
- Retest result: [actual outcome]
- Limitation: [anything the sample cannot establish]

Never claim an increase in donations, engagement, conversion, or completion rate without real measurements and a valid comparison.
